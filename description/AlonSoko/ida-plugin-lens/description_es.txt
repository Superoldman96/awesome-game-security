Plugin Lens es un complemento GUI para IDA Pro que reorganiza y enriquece el menú Editar › Complementos para que las listas largas de plugins sean más fáciles de recorrer. Asigna iconos desde el logo de ida-plugin.json de cada plugin, ilustraciones incluidas para entradas integradas o imágenes personalizadas en la carpeta plugin-lens del usuario, y nunca sobrescribe iconos que un plugin ya haya definido. Las entradas se agrupan en plugins integrados, plugins instalados con hcli por repositorio y plugins instalados manualmente, con números de versión en superíndice y etiquetas cuando hcli informa de versiones más recientes. Cuando hay actualizaciones disponibles, una acción del menú ejecuta el flujo de actualización de hcli desde IDA para los plugins seleccionados. Escrito en Python para IDA 9.0 y posteriores, está pensado para ingenieros inversos y analistas de malware o juegos que dependen de muchos plugins de IDA y del ecosistema hcli.
