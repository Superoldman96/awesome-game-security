Plugin Lens는 IDA Pro용 GUI 플러그인으로, 편집 › 플러그인 메뉴를 재구성하고 보강해 방대한 플러그인 목록을 더 쉽게 탐색할 수 있게 합니다. 각 항목 아이콘은 플러그인의 ida-plugin.json logo, 내장 항목용 번들 artwork, 또는 사용자 plugin-lens 폴더의 사용자 지정 이미지에서 할당하며, 플러그인이 이미 설정한 아이콘은 덮어쓰지 않습니다. 항목은 내장 플러그인, 저장소별 hcli 설치 플러그인, 수동 설치 플러그인으로 그룹화되고, 버전 번호는 위첨자로 표시되며 hcli가 더 새 릴리스를 알리면 태그도 표시합니다. 업데이트가 있을 때 메뉴 동작으로 IDA 안에서 선택한 플러그인에 대해 hcli 업그레이드 흐름을 실행할 수 있습니다. Python으로 작성되었으며 IDA 9.0 이상을 대상으로 하며, 많은 IDA 플러그인과 hcli 생태계에 의존하는 리버스 엔지니어 및 멀웨어·게임 분석가를 위한 도구입니다.
