Plugin Lens — GUI-плагин для IDA Pro, который упорядочивает и расширяет меню «Правка › Плагины», чтобы по длинным спискам плагинов было проще ориентироваться. Иконки берутся из logo в ida-plugin.json каждого плагина, из встроенной графики для штатных пунктов или из пользовательских изображений в папке plugin-lens; уже заданные плагином иконки не перезаписываются. Записи сгруппированы на встроенные плагины, установленные через hcli по репозиториям и установленные вручную; номера версий показываются в верхнем индексе, а при сообщении hcli о более новых релизах отображаются метки. При наличии обновлений действие меню запускает сценарий обновления hcli из IDA для выбранных плагинов. Написан на Python для IDA 9.0 и новее; рассчитан на специалистов по реверсу и аналитиков вредоносного ПО или игр, которые активно используют множество плагинов IDA и экосистему hcli.
