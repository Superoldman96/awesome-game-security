Plugin Lens 是一款 IDA Pro GUI 外掛，用於重組並強化「編輯 › 外掛」選單，使龐大的外掛清單更易瀏覽。它會為各項目分配圖示：來自各外掛 ida-plugin.json 中的 logo、內建項目的隨附 artwork，或使用者 plugin-lens 資料夾中的自訂圖片，且不會覆寫外掛已自行設定的圖示。項目分為內建外掛、依儲存庫分組的 hcli 安裝外掛，以及手動安裝的外掛；版本號以上標顯示，並在 hcli 回報有較新版本時顯示標籤。有可用更新時，選單動作可在 IDA 內對所選外掛執行 hcli 的升級流程。以 Python 撰寫，適用 IDA 9.0 及更新版本，面向依賴大量 IDA 外掛與 hcli 生態的逆向工程師以及惡意軟體或遊戲分析人員。
