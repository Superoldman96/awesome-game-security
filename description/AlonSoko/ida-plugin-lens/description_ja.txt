Plugin Lens は IDA Pro 用 GUI プラグインで、「編集 › プラグイン」メニューを整理・拡張し、多数のプラグイン一覧を探しやすくします。各エントリのアイコンは、プラグインの ida-plugin.json の logo、組み込み項目用の同梱 artwork、またはユーザーの plugin-lens フォルダ内のカスタム画像から割り当て、プラグインが既に設定しているアイコンは上書きしません。エントリは組み込みプラグイン、hcli でインストールしたプラグイン（リポジトリ別）、手動インストールのプラグインに分類され、バージョン番号は上付き文字で表示し、hcli が新しいリリースを報告した場合はタグも表示します。更新がある場合、メニュー操作から IDA 内で選択したプラグインに対して hcli のアップグレードフローを実行できます。Python で書かれ、IDA 9.0 以降向けで、多数の IDA プラグインと hcli エコシステムに依存するリバースエンジニアやマルウェア・ゲーム解析者を対象としています。
