Plugin Lens is an IDA Pro GUI plugin that reorganizes and enriches the Edit › Plugins menu so large plugin lists are easier to navigate. It assigns icons from each plugin’s ida-plugin.json logo, bundled artwork for built-in entries, or custom images in the user plugin-lens folder, and it never overwrites icons a plugin already sets. Entries are grouped into built-in plugins, hcli-installed plugins by repository, and manually installed plugins, with version numbers shown in superscript and tags when hcli reports newer releases. When updates are available, a menu action runs hcli’s upgrade flow from inside IDA for selected plugins. Written in Python for IDA 9.0 and later, it targets reverse engineers and malware or game analysts who rely on many IDA plugins and the hcli ecosystem.
