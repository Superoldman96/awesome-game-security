Plugin Lens è un plugin GUI per IDA Pro che riorganizza e arricchisce il menu Modifica › Plugin così da rendere più facile navigare elenchi lunghi di plugin. Assegna le icone dal logo in ida-plugin.json di ciascun plugin, dalle grafiche incluse per le voci integrate o da immagini personalizzate nella cartella plugin-lens dell’utente, e non sovrascrive mai le icone già impostate da un plugin. Le voci sono raggruppate in plugin integrati, plugin installati con hcli per repository e plugin installati manualmente, con numeri di versione in apice e tag quando hcli segnala release più recenti. Quando sono disponibili aggiornamenti, un’azione di menu avvia il flusso di upgrade di hcli da dentro IDA per i plugin selezionati. Scritto in Python per IDA 9.0 e versioni successive, è rivolto a reverse engineer e analisti di malware o giochi che si affidano a molti plugin IDA e all’ecosistema hcli.
