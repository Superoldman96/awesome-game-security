Plugin Lens 是一款 IDA Pro GUI 插件，用于重组并增强「编辑 › 插件」菜单，使庞大的插件列表更易于浏览。它会为各条目分配图标：来自各插件 ida-plugin.json 中的 logo、内置条目的捆绑 artwork，或用户 plugin-lens 文件夹中的自定义图片，且不会覆盖插件已自行设置的图标。条目分为内置插件、按仓库分组的 hcli 安装插件，以及手动安装的插件；版本号以上标显示，并在 hcli 报告有更新版本时显示标签。有可用更新时，菜单操作可在 IDA 内对所选插件执行 hcli 的升级流程。采用 Python 编写，面向 IDA 9.0 及更高版本，适合依赖大量 IDA 插件与 hcli 生态的逆向工程师以及恶意软件或游戏分析人员。
