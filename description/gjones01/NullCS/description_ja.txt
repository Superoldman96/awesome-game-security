NullCS は Counter-Strike 2 のデモファイルを解析し、tick 単位の挙動に基づき人間によるレビューが必要かどうかの度合いでプレイヤーをランク付けする研究システムであり、自動 BAN ではなく根拠付きの判断材料を提供する。ローカルの .dem リプレイを demoparser2 と awpy でパースし交戦ごとのウィンドウに分割したうえで、短いエイム・マウス・視認性・タイミングの系列に畳み込みニューラルネットワークを適用し、XGBoost モデルがプレイヤーあたり約 450 特徴量を集約してロビー順位を算出する。スタックは主に Python で解析・特徴量設計・学習・推論を担い、Next.js の Web UI と FastAPI 風ワーカーがアップロードおよびデスクトップ分析ワークフローを補完する。透明なオンマシン demo スクリーニングとベンチマーク可能なレビューシグナルを必要とするアナリスト、大会運営者、ゲームセキュリティ研究者向けで、本番アンチチート執行の代替ではなく補完として位置づけられる。
