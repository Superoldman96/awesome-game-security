NullCS는 Counter-Strike 2 데모 파일을 분석하고 tick 수준 행동이 사람의 검토를 얼마나 강하게 요구하는지에 따라 플레이어 순위를 매기는 연구 시스템으로, 자동 밴이 아니라 뒷받침 근거를 제공한다. demoparser2와 awpy로 로컬 .dem 리플레이를 파싱해 교전별 구간으로 나눈 뒤, 짧은 에임·마우스·가시성·타이밍 시퀀스에 합성곱 신경망을 적용하고, XGBoost 모델이 플레이어당 약 450개 특징을 집계해 로비 순위를 만든다. 스택은 주로 Python으로 파싱, 특징 공학, 학습, 추론을 담당하며 Next.js 웹 UI와 FastAPI 스타일 worker가 업로드 및 데스크톱 분석 워크플로를 보완한다. 투명한 온머신 데모 스크리닝과 벤치마크 가능한 검토 신호가 필요한 분석가, 토너먼트 관리자, 게임 보안 연구자를 대상으로 하며, 프로덕션 안티치트 집행의 대체가 아니라 보완으로 명시된다.
