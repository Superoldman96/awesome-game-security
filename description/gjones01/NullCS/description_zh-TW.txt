NullCS 是一套研究型系統，用於分析 Counter-Strike 2 的 demo 檔，並依玩家在 tick 級行為上是否值得人工複查的程度進行排名，提供佐證而非自動封禁。它透過 demoparser2 與 awpy 解析本機 .dem 重播，切分為逐次交火視窗，再對短時瞄準、滑鼠、可見性與時序序列套用卷積神經網路，隨後由 XGBoost 模型將約 450 項每名玩家的特徵彙總為大廳排名。技術棧以 Python 為主，負責解析、特徵工程、訓練與推論，並輔以 Next.js Web 介面及 FastAPI 風格 worker，支援上傳與桌面分析流程。面向需要透明、本機 demo 篩查與可基準化複查訊號的分析員、賽事管理員與遊戲安全研究人員，明確作為正式反作弊執法的補充，而非替代。
