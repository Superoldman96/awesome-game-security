NullCS 是一套研究型系统，用于分析 Counter-Strike 2 的 demo 文件，并根据玩家在 tick 级行为上是否值得人工复核的程度进行排名，提供佐证材料而非自动封禁。它通过 demoparser2 与 awpy 解析本地 .dem 回放，切分为逐次交火窗口，再对短时瞄准、鼠标、可见性与时序序列应用卷积神经网络，随后由 XGBoost 模型将约 450 项每名玩家的特征汇总为大厅排名。技术栈以 Python 为主，负责解析、特征工程、训练与推理，并辅以 Next.js Web 界面及 FastAPI 风格 worker，支持上传与桌面分析流程。面向需要透明、本地 demo 筛查与可基准化复核信号的分析员、赛事管理员与游戏安全研究人员，明确作为生产反作弊执法的补充，而非替代。
