MotorStorm Monument Valley は、PlayStation 3 版 MotorStorm をコンソールをエミュレートするのではなく、PPU および SPU のゲストコードを静的に変換して Windows 上で動かすことを目指す、進行中のネイティブ再コンパイルプロジェクトです。リポジトリには CMake ベースのビルド用設定、Python による解析・リフティング用スクリプト、および同梱の ps3recomp ランタイムが含まれ、Cell システムライブラリの高レベルエミュレーション、FFmpeg によるメディア処理、D3D12 グラフィックス経路が拡張されています。Havok 物理アセット、SPURS ジョブスケジューリング、埋め込み SPU ELF の抽出、ソースカバレッジ監査に関する調査を文書化しつつ、小売版バイナリ、鍵、生成されたリフト出力はローカルに保持します。主な言語は、ランナーとランタイムスタブ用の C++、およびツールと検証用の Python です。完成したプレイ可能ビルドの提供ではなく、PS3 実行ファイル構造、静的変換パイプライン、コンソールからネイティブへの移植を研究する保存活動者とリバースエンジニアを対象としています。
