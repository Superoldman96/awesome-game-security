MotorStorm Monument Valley est un effort de recompilation native en cours visant à exécuter le titre PlayStation 3 MotorStorm sous Windows en traduisant statiquement le code invité PPU et SPU plutôt qu’en émulant la console. Le dépôt fournit une chaîne de build basée sur CMake, des scripts Python d’analyse et de lifting, ainsi qu’un runtime ps3recomp intégré étendu avec une émulation de haut niveau des bibliothèques système Cell, un traitement média via FFmpeg et des chemins graphiques D3D12. Il documente des recherches sur les assets physiques Havok, la planification des tâches SPURS, l’extraction d’ELF SPU embarqués et l’audit de couverture de code source, tout en conservant localement les binaires retail, les clés et la sortie de lift générée. Les langages principaux sont le C++ pour le runner et les stubs runtime, et Python pour l’outillage et les contrôles de validation. Le projet s’adresse aux spécialistes de la préservation et aux ingénieurs reverse qui étudient la structure des exécutables PS3, les pipelines de traduction statique et le portage console vers natif, plutôt qu’à la livraison d’une build jouable aboutie.
