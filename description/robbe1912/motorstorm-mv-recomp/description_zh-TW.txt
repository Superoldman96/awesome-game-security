MotorStorm Monument Valley 是一項進行中的原生重編譯專案，目標是透過在 Windows 上靜態轉譯其 PPU 與 SPU 客端程式碼（而非模擬主機），來執行 PlayStation 3 遊戲 MotorStorm。本儲存庫提供以 CMake 為基礎的建置腳本、Python 分析與 lifting 工具，以及內建的 ps3recomp 執行階段；後者擴充了對 Cell 系統函式庫的高階模擬、以 FFmpeg 為後端的媒體處理，以及 D3D12 圖形路徑。專案記錄了對 Havok 物理資產、SPURS 工作排程、內嵌 SPU ELF 擷取與原始碼覆蓋率稽核的研究，同時將零售版二進位、金鑰與產生的 lift 輸出保留在本地。主要語言為 C++（執行器與執行階段 stub）與 Python（工具與驗證）。對象是研究 PS3 可執行檔結構、靜態轉譯管線與主機到原生移植的保存研究者與逆向工程師，而非交付可玩的成品建置。
