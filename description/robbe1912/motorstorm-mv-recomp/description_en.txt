MotorStorm Monument Valley is a work-in-progress native recompilation effort that aims to run the PlayStation 3 title MotorStorm on Windows by statically translating its PPU and SPU guest code instead of emulating the console. The repository ships CMake-based build glue, Python analysis and lifting scripts, and a vendored ps3recomp runtime extended with high-level emulation for Cell system libraries, FFmpeg-backed media, and D3D12 graphics paths. It documents research into Havok physics assets, SPURS job scheduling, embedded SPU ELF extraction, and source-coverage auditing while keeping retail binaries, keys, and generated lift output local. Primary languages are C++ for the runner and runtime stubs and Python for tooling and validation checks. The project targets preservationists and reverse engineers studying PS3 executable structure, static translation pipelines, and console-to-native porting rather than shipping a finished playable build.
