MotorStorm Monument Valley — это проект нативной перекомпиляции в разработке, цель которого запустить игру MotorStorm для PlayStation 3 в Windows путём статического перевода гостевого кода PPU и SPU, а не эмуляции консоли. Репозиторий содержит сборочную инфраструктуру на CMake, скрипты анализа и lifting на Python, а также встроенную среду выполнения ps3recomp с расширенной высокоуровневой эмуляцией системных библиотек Cell, медиа на базе FFmpeg и графическими путями D3D12. Документируются исследования активов физики Havok, планирования задач SPURS, извлечения встроенных SPU ELF и аудита покрытия исходного кода, при этом розничные бинарники, ключи и сгенерированный вывод lift остаются локально. Основные языки — C++ для runner и заглушек runtime и Python для инструментов и проверок. Проект ориентирован на специалистов по сохранению и reverse engineers, изучающих структуру исполняемых файлов PS3, конвейеры статического перевода и портирование с консоли на нативную платформу, а не на выпуск готовой играбельной сборки.
