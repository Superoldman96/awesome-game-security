Kernel Loader 是一款已 root 的 Android 應用程式，可偵測裝置目前執行的核心，並從空中（OTA）驅動資料庫或內建備援載入相符的預編譯核心模組。應用程式主要以 Kotlin 撰寫，採用 Jetpack Compose 介面，並透過 libsu 在 Magisk、KernelSU 或 APatch 環境下執行 insmod、驗證以及可選的開機時重載腳本。隨附的 RT 與 QX 驅動透過 misc 裝置及 ioctl 提供跨行程實體記憶體讀寫、模組基底位址查詢、批次讀取與隱蔽卸載，底層由涵蓋 Linux 核心 4.9 至 6.6 的共用 C 驅動引擎支撐。應用程式還包含 SafetyGuard 檢查、簽章與防篡改保護、應用程式內更新，以及在沒有完全相符驅動時自動產生建置請求報告。面向需要在 arm64 手機上可靠進行核心級記憶體存取的開發者與研究人員，適用於遊戲修改、作弊工具及逆向工程等工作流程。
