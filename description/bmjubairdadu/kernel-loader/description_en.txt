Kernel Loader is a rooted Android application that detects the device’s running kernel and loads a matching prebuilt kernel module from an over-the-air driver database or embedded fallbacks. It is written primarily in Kotlin with a Jetpack Compose UI and uses libsu to run insmod, verification, and optional boot-time reload scripts under Magisk, KernelSU, or APatch. The bundled RT and QX drivers expose a misc device with ioctls for cross-process physical memory read, write, module-base lookup, batch reads, and stealth unload, backed by a shared C driver engine spanning Linux kernels 4.9 through 6.6. The app adds SafetyGuard checks, signature and anti-tamper protections, in-app updates, and automated build-request reports when no exact driver exists. It targets developers and researchers who need reliable kernel-level memory access on arm64 phones, including game modding, cheat tooling, and reverse engineering workflows.
