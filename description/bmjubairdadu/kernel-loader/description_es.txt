Kernel Loader es una aplicación Android con root que detecta el kernel en ejecución del dispositivo y carga un módulo de kernel precompilado coincidente desde una base de datos de controladores over-the-air o respaldos integrados. Está escrita principalmente en Kotlin con una interfaz Jetpack Compose y usa libsu para ejecutar insmod, verificación y scripts opcionales de recarga al arranque bajo Magisk, KernelSU o APatch. Los controladores RT y QX incluidos exponen un dispositivo misc con ioctls para lectura y escritura de memoria física entre procesos, búsqueda de base de módulo, lecturas por lotes y descarga sigilosa, respaldados por un motor de controlador C compartido que abarca kernels Linux 4.9 a 6.6. La app añade comprobaciones SafetyGuard, protecciones de firma y anti-manipulación, actualizaciones in-app e informes automáticos de solicitud de compilación cuando no existe un controlador exacto. Está dirigida a desarrolladores e investigadores que necesitan acceso fiable a memoria a nivel de kernel en teléfonos arm64, incluido modding de juegos, herramientas de trampas y flujos de ingeniería inversa.
