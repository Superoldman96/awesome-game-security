Kernel Loader は root 済み Android アプリで、端末で動作中のカーネルを検出し、OTA ドライバデータベースまたは組み込みフォールバックから一致する事前ビルド済みカーネルモジュールを読み込みます。主に Kotlin で書かれ、Jetpack Compose UI を用い、libsu 経由で Magisk、KernelSU、または APatch 上で insmod、検証、任意の起動時リロードスクリプトを実行します。同梱の RT および QX ドライバは misc デバイスと ioctl で、プロセス間の物理メモリ読み書き、モジュールベースアドレス検索、バッチ読み取り、ステルスアンロードを提供し、Linux カーネル 4.9 から 6.6 までをカバーする共通 C ドライバエンジンに支えられています。SafetyGuard チェック、署名と改ざん防止、アプリ内更新、完全一致するドライバがない場合の自動ビルド要求レポートも備えます。arm64 スマートフォンで信頼性の高いカーネルレベルのメモリアクセスが必要な開発者や研究者向けで、ゲーム改造、チートツール、リバースエンジニアリングのワークフローに対応します。
