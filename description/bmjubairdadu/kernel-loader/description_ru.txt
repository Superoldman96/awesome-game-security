Kernel Loader — root-приложение для Android, которое определяет работающее на устройстве ядро и загружает подходящий предсобранный модуль ядра из OTA-базы драйверов или встроенных резервных вариантов. Написано в основном на Kotlin с интерфейсом Jetpack Compose и использует libsu для выполнения insmod, проверки и необязательных скриптов перезагрузки при загрузке под Magisk, KernelSU или APatch. В комплекте драйверы RT и QX предоставляют misc-устройство с ioctl для межпроцессного чтения и записи физической памяти, поиска базы модуля, пакетного чтения и скрытой выгрузки на основе общего движка драйвера на C для ядер Linux с 4.9 по 6.6. В приложении есть проверки SafetyGuard, защита подписи и от подмены, обновления внутри приложения и автоматические отчёты о запросе сборки, если точного драйвера нет. Ориентировано на разработчиков и исследователей, которым нужен надёжный доступ к памяти на уровне ядра на arm64-телефонах, включая моддинг игр, инструменты для читов и сценарии реверс-инжиниринга.
