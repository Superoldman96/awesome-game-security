Kernel Loader 是一款已 root 的 Android 应用，可检测设备当前运行的内核，并从空中（OTA）驱动数据库或内置备用方案加载匹配的预编译内核模块。应用主要使用 Kotlin 编写，采用 Jetpack Compose 界面，并通过 libsu 在 Magisk、KernelSU 或 APatch 环境下执行 insmod、校验以及可选的启动时重载脚本。捆绑的 RT 与 QX 驱动通过 misc 设备及 ioctl 提供跨进程物理内存读写、模块基址查询、批量读取与隐蔽卸载，底层由覆盖 Linux 内核 4.9 至 6.6 的共享 C 驱动引擎支撑。应用还包含 SafetyGuard 检查、签名与防篡改保护、应用内更新，以及在没有完全匹配驱动时自动生成构建请求报告。面向需要在 arm64 手机上可靠进行内核级内存访问的开发者与研究人员，适用于游戏修改、作弊工具及逆向工程等工作流。
