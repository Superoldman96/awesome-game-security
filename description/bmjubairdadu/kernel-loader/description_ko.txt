Kernel Loader는 root된 Android 앱으로, 기기에서 실행 중인 커널을 감지하고 OTA 드라이버 데이터베이스 또는 내장 폴백에서 일치하는 사전 빌드 커널 모듈을 로드합니다. 주로 Kotlin으로 작성되었으며 Jetpack Compose UI를 사용하고, libsu를 통해 Magisk, KernelSU 또는 APatch 환경에서 insmod, 검증 및 선택적 부팅 시 재로드 스크립트를 실행합니다. 번들된 RT 및 QX 드라이버는 misc 장치와 ioctl로 프로세스 간 물리 메모리 읽기·쓰기, 모듈 베이스 조회, 일괄 읽기, 은밀 언로드를 제공하며, Linux 커널 4.9부터 6.6까지를 아우르는 공유 C 드라이버 엔진을 기반으로 합니다. SafetyGuard 검사, 서명 및 변조 방지, 앱 내 업데이트, 정확히 맞는 드라이버가 없을 때 자동 빌드 요청 보고 기능을 추가했습니다. arm64 휴대폰에서 신뢰할 수 있는 커널 수준 메모리 접근이 필요한 개발자와 연구자를 대상으로 하며, 게임 모딩, 치트 도구, 리버스 엔지니어링 워크플로에 맞춰져 있습니다.
