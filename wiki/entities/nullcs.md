# NullCS

**NullCS** (gjones01/NullCS) is an **offline Counter-Strike 2 demo (`.dem`) analysis pipeline** that extracts tick-level aim and visibility features, ranks players, and emits **evidence tables for human review**—explicitly **not** an automated ban system. Listed under README **Anti Cheat / Analysis Framework**. (source: wiki/sources/README-categories.md)

## Positioning

Complements offline CS2 review benches such as [[cs2-overwatch]] (layered rules, visibility geometry, ML + optional LLM narration), [[yaacs-anticheat]] (demo pitch/yaw telemetry research), and explainable scoring tools such as [[cs2-tracker]] with a **tick-feature ranking + tabular evidence** emphasis and human-in-the-loop enforcement boundaries.
