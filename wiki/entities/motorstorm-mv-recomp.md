# MotorStorm MV Recomp

**motorstorm-mv-recomp** (robbe1912/motorstorm-mv-recomp) is **source-only** tooling for PlayStation 3 *MotorStorm: Monument Valley* static recompilation and translation, built on **ps3recomp**, aimed at authorized local reverse engineering and native Windows experiments—not a redistributable game port. Listed under README **Cheat / RE Tools**. (source: wiki/sources/README-categories.md)

## Positioning

Sits beside console static-recompilation research such as [[saturnkit]] (Saturn SH-2→C++), [[mcla-pc]] / [[dead-rising-2-case-zero-xenon-recomp]] (Xbox 360 XenonRecomp), and [[jsrf-recomp]] (OG Xbox XBE recomp) as a **PS3 Cell/PPU translation** lane for title-specific authorized RE workflows.
